Tentang KLATOS

KLATOS adalah sistem operasi native yang dikembangkan oleh WSM SOFTWARE dengan arsitektur, kernel, keamanan, runtime, desktop, filesystem, serta platform aplikasi yang dirancang sebagai satu ekosistem terpadu.

Visi

KLATOS strive untuk menjadi operating system dengan identitas, arsitektur, application model, package system, shell, developer environment, filesystem UX, desktop, dan ecosystem sendiri — dibangun dari kernel sampai aplikasi.

Filosofi KLATOS

1

Native

Setiap komponen utama dirancang untuk menjadi bagian dari platform KLATOS.

2

Secure

Keamanan menjadi bagian dari fondasi kernel dan resource management.

3

Modular

Kernel, service, graphical stack, runtime, dan aplikasi memiliki batas interface yang jelas.

4

Integrated

Kernel, security, IPC, filesystem, runtime, desktop, dan application platform bekerja sebagai satu ekosistem.

5

Developer Friendly

KLATOS menyediakan DevKit dan KlatCLI untuk membangun aplikasi native secara langsung.

Apa yang Membuat KLATOS Berbeda

🏠 Ekosistem Sendiri

Kernel, security, IPC, filesystem, runtime, desktop, developer tools, dan application platform dalam satu ekosistem.

⚖ Kernel & Security Native

JowoKernel dan KSM menjadi fondasi sistem, bukan lapisan tambahan di atas sistem operasi lain.

📦 Application Model Native

Aplikasi native dibuild, dipaketkan sebagai .kap, dicatat, dan HUM launched melalui AppRegistry.

📁 Filesystem UX Native

Struktur filesystem native dengan /Sistem sebagai pusat sistem.

🖥 Desktop Terpadu

KlatGUI dan Nawolo menyediakan graphical environment yang menyatu dengan runtime dan aplikasi.

💻 Developer Experience

KLATOS DevKit dan KlatCLI menyatukan create, build, run, package, dan install.

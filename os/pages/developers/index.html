Developer

Bangun aplikasi native KLATOS dengan DevKit, KlatCLI, ABI v2, dan KAP.

Prinsip Developer KLATOS

Native

Setiap komponen baru menjadi bagian native dari platform KLATOS.

Capability-first

Resource direpresentasikan sebagai capability, bukan daftar permission.

Explicit boundary

Komunikasi service melewati boundary melalui KlatIPC.

ABI v2

Interface baru mengikuti karakteristik ABI-v2 yang terstruktur.

Single authority

Setiap akses object melewati KSM. Tidak ada security table kedua.

Runtime proof

Mekanisme yang menentukan harus dibuktikan pada runtime nyata.

Developer Ecosystem

🔧

Native Toolchain

GCC, G++, GCCGo, CMake, Git, dan Bash pada /Sistem/DevKit/.

📚

Libraries & Headers

Header dan library native pada /Sistem/DevKit/include dan /Sistem/Perpustakaan.

📋

Build System

CMake menghasilkan native executable untuk target platform x86_64-klatos.

〈

KlatCLI

klat new, build, run, package, dan install sebagai workflow developer.

✅

Validation & Testing

Host tests, integration tests, kernel tests, QEMU boot tests, dan userspace witness.

Workflow Aplikasi

$
klat new MyApp
$
klat build
$
klat run
$
klat package
$
klat install

Hasil akhirnya adalah MyApp.kap yang dapat dipasang melalui KAP, dicatat oleh AppRegistry, dan dignidad launched melalui AppLauncher.

$
klat package → MyApp.kap

Komponen Ekosistem

  • JowoKernelKernel native untuk memory, process, thread, scheduler, VFS, IPC, security, dan resource.
  • KSMOtoritas capability untuk seluruh resource sistem.
  • KlatIPCKomunikasi antarproses native.
  • KlatLoaderRuntime loader native pada /Sistem/Runtime/KlatLoader.so.
  • KlatGUIToolkit graphical user interface native.
  • NawoloWindow system dan compositor.
  • KAPFormat paket aplikasi .kap.
  • KLATOS DevKitLingkungan pengembangan native pada /Sistem/DevKit/.
  • KlatCLICommand-line interface native.

Dokumentasi KLATOS

Rujukan teknis resmi untuk arsitektur, kernel, keamanan, runtime, desktop, filesystem, dan platform aplikasi KLATOS.

Tentang KLATOS

KLATOS adalah sistem operasi native yang dikembangkan oleh WSM SOFTWARE dengan arsitektur, kernel, keamanan, runtime, desktop, filesystem, serta platform aplikasi yang dirancang sebagai satu ekosistem terpadu.

KLATOS adalah sistem operasi native yang menggabungkan kernel, security, IPC, filesystem, runtime, graphical environment, developer tools, dan application platform dalam satu ekosistem.

KLATOS adalah sistem operasi native dengan arsitektur, kernel, keamanan, runtime, desktop, filesystem, dan platform aplikasi yang dirancang sebagai satu ekosistem terpadu.

KLATOS — Native Kernel. Native Runtime. Native Platform.

Fondasi Utama

  • Native Kernel — JowoKernel mengatur seluruh fondasi sistem.
  • Native Security — KSM mengatur otoritas dan hak akses resource.
  • Native Runtime — KlatLoader dan system services membentuk lingkungan eksekusi.
  • Native Desktop — KlatGUI dan Nawolo menyediakan lingkungan graphical.
  • Native Applications — KAP dan KlatCLI menjadi platform aplikasi.

Filosofi KLATOS

Lima prinsip yang menentukan arah seluruh komponen KLATOS.

1

2

3

4

5

Developer Friendly

JowoKernel

JowoKernel adalah kernel native KLATOS. JowoKernel mengatur fondasi utama sistem:

  • Memory Management
  • Process Management
  • Thread Management
  • Scheduler
  • Virtual Memory
  • Address Space
  • Filesystem
  • Resource Management
  • Inter-Process Communication
  • Security
  • Capability
  • Synchronization
  • Timer
  • Device Management
  • System Call
  • Kernel Boot

JowoKernel menggunakan Rust sebagai fondasi utama mekanisme dan otoritas kernel, dengan komponen low-level yang digunakan untuk kebutuhan hardware, arsitektur prosesor, bootstrap, dan interface perangkat.

Arsitektur Kernel

JowoKernel memisahkan tanggung jawab mechanism per subsistem dengan batas interface yang jelas.

SubsystemTanggung jawab

ProcessProcess lifecycle, address space, dan resource usage.
ThreadThread lifecycle, scheduling entity, dan synchronization.
SchedulerPenjadwalan thread berdasarkan priority dan state.
VFSFilesystem, namespace, file, dan directory.
IPCEndpoint, request, response, dan error status.
SecurityCapability, rights, dan admission decision.
ResourceResource ownership, accounting, dan reclamation.

Memory Management

Memory management JowoKernel menangani alokasi memori, address space, dan virtual memory untuk seluruh process dan thread.

  • Alokasi dan dealokasi memori.
  • Address space milik setiap process.
  • Virtual memory dan pemetaan halaman.
  • Resource accounting untuk setiap alokasi.

Virtual Memory & Address Space

Virtual memory memisahkan address space logis setiap process dari address space fisik. Akses memori selalu divalidasi oleh mekanisme kernel dan KSM.

Process & Thread

JowoKernel mengatur process dan thread sebagai entitas native dengan lifecycle yang jelas.

  • Process memiliki address space, capability, dan resource sendiri.
  • Thread merupakan scheduling entity di dalam process.
  • Synchronization dijamin oleh mekanisme kernel.
  • Process dan thread hanya dapat melakukan operasi melalui ABI dan KlatIPC.

Scheduler

Scheduler JowoKernel menentukan urutan eksekusi thread berdasarkan priority, state, dan preemption.

Device Management

Device layer JowoKernel menangani device dan hardware melalui interface yang terkontrol.

  • Device discovery
  • Device driver interface
  • Interrupt handling
  • DMA
  • MMIO
  • VirtIO

Akses ke device selalu melewati mekanisme kernel dan KSM.

Network

Network subsystem KLATOS mencakup endpoint, socket, dan pertukaran data antar node.

  • Endpoint sebagai target komunikasi.
  • Socket sebagai interface aplikasi.
  • Transfer data melalui KlatIPC dan system service.

Input System

Input dipisahkan dari GUI toolkit. Aplikasi tidak mengakses hardware input secara langsung.

KlatLoader

KlatLoader adalah runtime loader native KLATOS. KlatLoader menangani pemuatan executable dan library ke dalam lingkungan KLATOS.

Runtime utama berada pada: /Sistem/Runtime/KlatLoader.so

KlatLoader menjadi bagian penting dari native execution environment KLATOS.

KSM

KSM adalah sistem keamanan native KLATOS. KSM mengatur otoritas dan hak akses terhadap resource sistem melalui mekanisme capability.

Resource sistem dapat berupa:

  • Memory
  • Device
  • Endpoint
  • Task
  • Service
  • File
  • Directory
  • Keymap

Prinsip Utama KSM

Capability
     │
     ├── Validate
     ├── Derive
     ├── Transfer
     └── Revoke

KSM memastikan setiap operasi dilakukan dengan authority yang valid.

Capability

Capability adalah otoritas yang dapat divalidasi, diturunkan, ditransfer, dan dicabut.

  • Identity — setiap capability memiliki identitas.
  • Rights — capability menentukan operasi yang diizinkan.
  • Validation — capability divalidasi oleh KSM sebelum digunakan.
  • Transfer — capability dapat diteruskan melalui KlatIPC.
  • Revoke — capability dapat dicabut sehingga tidak lagi berlaku.

Security Architecture

Keamanan KLATOS dibangun dengan beberapa prinsip utama.

  • Capability — akses terhadap resource dikendalikan melalui capability.
  • Least Privilege — komponen memperoleh authority sesuai kebutuhan.
  • Explicit Authority — akses resource harus memiliki authority yang valid.
  • Isolation — process dan service memiliki batas akses yang terkontrol.
  • Resource Ownership — JowoKernel mengendalikan kepemilikan resource sistem.
  • Fail Closed — operasi tanpa authority yang valid ditolak.

KlatIPC

KlatIPC adalah sistem komunikasi antarproses KLATOS. KlatIPC memungkinkan:

  • aplikasi berkomunikasi dengan service
  • service berkomunikasi dengan service lain
  • komunikasi antara aplikasi dan sistem
  • pertukaran data melalui endpoint
  • pengiriman resource menggunakan capability

ABI KLATOS

KLATOS memiliki ABI native yang menjadi kontrak antara kernel, service, runtime, dan aplikasi. ABI menyediakan:

  • System Call
  • Object
  • Handle
  • Capability
  • Rights
  • Request
  • Response
  • Error Status
  • IPC Interface

ABI v2

ABI v2 menyediakan interface terstruktur untuk mekanisme native KLATOS: append-only, pointer-free, explicit object kinds, dan structured request/response.

ABI v2 menjadi interface native yang digunakan pada seluruh operasi KLATOS modern.

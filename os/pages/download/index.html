Isi Ekosistem

  • JowoKernelKernel native: memory, process, thread, scheduler, VFS, IPC, security, resource management.
  • KSMKlat Security Manager: otoritas capability dan keputusan akses.
  • KlatIPCNative inter-process communication untuk aplikasi dan service.
  • KlatLoaderRuntime loader native pada /Sistem/Runtime/KlatLoader.so.
  • KlatGUIFramework graphical user interface native.
  • NawoloWindow system dan compositor.
  • KAPKlat Application Package dengan format .kap.
  • KLATOS DevKitLingkungan pengembangan native pada /Sistem/DevKit/.
  • KlatCLICommand-line interface native untuk workflow pengembangan.

Menjalankan di Emulator

Developer build KLATOS dapat dijalankan pada emulator untuk pengujian kernel, desktop, dan aplikasi native.

$
qemu-system-x86_64 —enable-kvm —cdrom klatos-dev.img

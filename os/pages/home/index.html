Keamanan

KSM mengatur otoritas dan hak akses terhadap resource sistem melalui mekanisme capability.

KSM adalah sistem keamanan native KLATOS. KSM mengatur otoritas dan hak akses terhadap resource sistem melalui mekanisme capability.

Capability

Resource sistem dapat berupa memory, device, endpoint, task, service, file, directory, dan keymap.

Authority

KSM memastikan setiap operasi dilakukan dengan authority yang valid. Prinsip utamanya: validate, derive, transfer, dan revoke.

Fail Closed

Operasi tanpa authority yang valid ditolak. Tidak ada security table kedua yang dapat menghasilkan keputusan berbeda.

KAP — Klat Application Package

Format paket aplikasi: .kap. KAP menyediakan struktur paket untuk executable, library, resource, dan metadata aplikasi KLATOS.

KlatLoader

Runtime loader native KLATOS yang menangani pemuatan executable dan library. Runtime utama berada pada /Sistem/Runtime/KlatLoader.so.

KLATOS DevKit & KlatCLI

DevKit dan KlatCLI unify creating, building, testing, packaging, and installing native applications.

Komponen Platform

Komponen utama yang membentuk ekosistem KLATOS.

⚖

JowoKernel

Kernel native KLATOS: memory, process, thread, scheduler, virtual memory, address space, filesystem, resource management, IPC, security, capability, synchronization, timer, device management, system call, dan kernel boot.

🔒

KSM

Sistem keamanan native KLATOS yang mengatur otoritas dan hak akses resource melalui mekanisme capability.

📡

KlatIPC

Sistem komunikasi antarproses native KLATOS untuk aplikasi, service, dan pertukaran data melalui endpoint.

📦

KlatLoader

Runtime loader native KLATOS untuk memuat executable dan library ke dalam lingkungan KLATOS.

🖥

KlatGUI

Framework graphical user interface native KLATOS: window, widget, application UI, input, rendering, layout, dan desktop integration.

▦

Nawolo

Window system dan compositor KLATOS: window management, desktop surface, compositing, pointer, input routing, dan application presentation.

📦

KAP

Klat Application Package: struktur paket untuk executable, library, resource, dan metadata aplikasi dengan format .kap.

💻

KLATOS DevKit

Lingkungan pengembangan native KLATOS di /Sistem/DevKit/ dengan compiler, library, header, dan development tools.

Status Komponen Platform

JowoKernel — Kernel native

Tersedia

  • Memory, process, thread, scheduler, virtual memory, dan address space.
  • VFS, filesystem, dan resource management.
  • IPC, synchronization, timer, device management, system call, dan kernel boot.
  • Rust sebagai fondasi utama mekanisme dan otoritas kernel.
Dokumentasi

KSM — Klat Security Manager

Tersedia

  • Otoritas tunggal untuk capability dan permission decisions.
  • Capability: validate, derive, transfer, revoke.
  • Resource: memory, device, endpoint, task, service, file, directory, keymap.
Dokumentasi

KlatIPC — Native IPC

Tersedia

  • Komunikasi aplikasi dengan service dan service dengan service.
  • Pertukaran data melalui endpoint.
  • Pengiriman resource menggunakan capability.
Dokumentasi

KlatLoader — Runtime Loader

Tersedia

  • Memuat executable dan library ke lingkungan KLATOS.
  • Runtime utama pada /Sistem/Runtime/KlatLoader.so.
Dokumentasi

KlatGUI & Nawolo — Graphical Environment

Tersedia

  • KlatGUI: window, widget, application UI, input, rendering, layout.
  • Nawolo: window management, desktop surface, compositing, pointer, input routing.
  • Desktop, taskbar, dock, launcher, dan system tray.
Dokumentasi

KAP — Application Package

Tersedia

  • Format paket .kap untuk executable, library, resource, dan metadata.
  • Install, AppRegistry, dan launch sebagai alur aplikasi native.
Dokumentasi

KLATOS DevKit & KlatCLI — Developer Toolchain

Tersedia

  • DevKit pada /Sistem/DevKit/ dengan GCC, G++, GCCGo, CMake, Git, dan Bash.
  • KlatCLI: klat new, build, run, package, install.
Dokumentasi

ABI v2 — Native Interface

Tersedia

  • System call, object, handle, capability, rights, request, response, error status.
  • Interface terstruktur: append-only, pointer-free, explicit object kinds.
Dokumentasi

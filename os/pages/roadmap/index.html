Peta Jalan

Arah pengembangan platform KLATOS sebagai satu ekosistem terpadu.

Platform KLATOS

Peta jalan KLATOS mengikuti satu ekosistem: kernel, security, IPC, filesystem, runtime, desktop, dan platform aplikasi.

JowoKernel

Kernel

  • Memory, process, thread, scheduler
  • Virtual memory dan address space
  • VFS dan resource management
  • Device, timer, synchronization

KSM

Security

  • Capability validate, derive, transfer, revoke
  • Resource: memory, device, endpoint, task, service, file
  • Single authority untuk access decisions

KlatIPC & ABI v2

IPC & ABI

  • Endpoint dan request/response terstruktur
  • Capability transfer antar process
  • Error status contract

KlatLoader & Runtime

Runtime

  • Executable dan library loading
  • Native runtime pada /Sistem/Runtime
  • System services: display, graphics, input, filesystem

KlatGUI & Nawolo

Desktop

  • Window, widget, layout, dan rendering
  • Window management dan compositing
  • Desktop, taskbar, dock, launcher, system tray

KAP & KlatCLI

Application Platform

  • Format paket .kap
  • Install, AppRegistry, dan launch
  • Workflow klat new sampai klat install

KLATOS DevKit

Developer Toolchain

  • GCC, G++, GCCGo, CMake, Git, Bash
  • Header, library, compiler runtime
  • Target platform x86_64-klatos

Hardware & Emulator

Platform

  • CPU, GPU, PCI, USB, storage, NVMe, network
  • Interrupt, DMA, MMIO, VirtIO
  • Boot dan runtime pada emulator

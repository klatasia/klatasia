JowoKernel

JowoKernel adalah kernel native KLATOS. JowoKernel mengatur fondasi utama sistem:

  • Memory Management
  • Process Management
  • Thread Management
  • Scheduler
  • Virtual Memory
  • Address Space
  • Filesystem
  • Resource Management
  • Inter-Process Communication
  • Security
  • Capability
  • Synchronization
  • Timer
  • Device Management
  • System Call
  • Kernel Boot

JowoKernel menggunakan Rust sebagai fondasi utama mekanisme dan otoritas kernel, dengan komponen low-level yang digunakan untuk kebutuhan hardware, arsitektur sistem, bootstrap, dan interface perangkat.

KSM

KSM adalah sistem keamanan native KLATOS. KSM mengatur otoritas dan hak akses terhadap resource sistem melalui mekanisme capability.

Resource

  • Memory
  • Device
  • Endpoint
  • Task
  • Service
  • File
  • Directory
  • Keymap
Capability
     │
     ├── Validate
     ├── Derive
     ├── Transfer
     └── Revoke

KSM memastikan setiap operasi dilakukan dengan authority yang valid.

KlatIPC

KlatIPC adalah sistem komunikasi antarproses KLATOS. KlatIPC memungkinkan:

  • aplikasi berkomunikasi dengan service
  • service berkomunikasi dengan service lain
  • komunikasi antara aplikasi dan sistem
  • pertukaran data melalui endpoint
  • pengiriman resource menggunakan capability

Security Architecture

Keamanan KLATOS dibangun dengan beberapa prinsip utama.

  • Capability — akses terhadap resource dikendalikan melalui capability.
  • Least Privilege — komponen memperoleh authority sesuai kebutuhan.
  • Explicit Authority — akses resource harus memiliki authority yang valid.
  • Isolation — process dan service memiliki batas akses yang terkontrol.
  • Resource Ownership — JowoKernel mengendalikan kepemilikan resource sistem.
  • Fail Closed — operasi tanpa authority yang valid ditolak.

ABI KLATOS

KLATOS memiliki ABI native yang menjadi kontrak antara kernel, service, runtime, dan aplikasi. ABI menyediakan:

  • System Call
  • Object
  • Handle
  • Capability
  • Rights
  • Request
  • Response
  • Error Status
  • IPC Interface

ABI v2 menyediakan interface terstruktur untuk mekanisme native KLATOS.

Filosofi KLATOS

  • Native — setiap komponen utama dirancang untuk menjadi bagian dari platform KLATOS.
  • Secure — keamanan menjadi bagian dari fondasi kernel dan resource management.
  • Modular — kernel, service, graphical stack, runtime, dan aplikasi memiliki batas interface yang jelas.
  • Integrated — kernel, security, IPC, filesystem, runtime, desktop, dan application platform bekerja sebagai satu ekosistem.
  • Developer Friendly — KLATOS menyediakan DevKit dan KlatCLI untuk membangun aplikasi native secara langsung.
